# OpenRouter Product Search

AI используется **только для внешнего обнаружения ссылок и извлечения цитируемого названия**. Он не сопоставляет Regard с Hardware, не выбирает детали, не решает совместимость и не вычисляет FPS/технические характеристики.

## Ключ и конфигурация

Ключ задаётся на backend в `backend/.env`:

```dotenv
OPENROUTER_API_KEY=ваш_ключ_OpenRouter
```

На Amvera это серверный секрет/переменная окружения; конкретный интерфейс платформы здесь не предполагается. Не использовать VITE-переменные и не передавать ключ браузеру. Реальный `.env` этой итерацией не переписывался. Settings использует SecretStr, исключение из repr/model_dump; заголовки авторизации и ответы с секретами не журналируются.

По умолчанию поиск выключен, модель не назначена и бюджет веб-инструментов равен нулю. Отдельное включение:

```dotenv
OPENROUTER_PRIMARY_MODEL=идентификатор_проверенной_модели:free
OPENROUTER_FALLBACK_MODEL=
OPENROUTER_SEARCH_ENABLED=false
OPENROUTER_ALLOW_PAID_WEB=false
OPENROUTER_DAILY_REQUESTS=20
OPENROUTER_DAILY_TOKENS=100000
OPENROUTER_DAILY_WEB_MICROUSD=0
OPENROUTER_MAX_OUTPUT_TOKENS=1200
OPENROUTER_TIMEOUT_SECONDS=20
```

Не включать платный режим без решения оператора и лимита расходов в аккаунте провайдера. Бесплатная модель не означает бесплатный поиск.

## Фактическая проверка 10.11.2026

Публичный [Models API](https://openrouter.ai/api/v1/models) подтвердил все три ID. Выполнено три минимальных вызова без tools, без платного веб-поиска:

| Модель | Ответ | Вывод |
| --- | --- | --- |
| nvidia/nemotron-3.5-lightning:free | 200 | доступна для минимального вызова; tools заявлены, structured_outputs/response_format не заявлены |
| google/gemma-4-31b-it:free | 429 | каталог содержит ID; практическая доступность сейчас ограничена |
| nvidia/nemotron-3-ultra-550b-a55b:free | 200 | минимальный вызов доступен; качество поиска не измерено |

Успешные вызовы сообщили cost=0. Это **не** проверка качества JSON, точного SKU или веб-поиска: минимального лимита могло хватить только на reasoning. Основная модель не назначена автоматически. Санитизированный локальный отчёт: `.artifacts/catalog-intelligence/openrouter-probe.json`.

[Официальный Web Search](https://openrouter.ai/docs/guides/features/server-tools/web-search): OpenRouter server tool `openrouter:web_search`, Exa instant $0.007 за поиск до 10 результатов. Используется один tool call, max_uses=1, max_results/max_total_results=3, max_characters=1000, ограничение доменов. Native-движок не выбирается: поддержка ограничений может различаться. Резерв $0.007 на каждую попытку, включая fallback; отказ/тайм-аут не возвращает резерв. Тариф необходимо перепроверять перед включением. Дополнительно установите внешний account/key spending cap: локальное резервирование не заменяет биллинг провайдера.

[Web Fetch](https://openrouter.ai/tool/web-fetch/) исследован как отдельный серверный инструмент; его фактическая доступность для аккаунта и стоимость вызова не подтверждены, он **не передаётся модели и не вызывается**. Платный Web Search тоже фактически не вызывался: отдельного разрешения на расход не было. Бесплатность глобального поиска не обещается. Из альтернатив изучен [Brave Search API](https://brave.com/search/api/): платный Search с месячным кредитом; карточка/условия хранения и выбранного тарифа требуют проверки. Отдельный ключ не предоставлен, интеграция не активирована.

## Границы доверия

Вход: модель, категория, бюджет, coarse city из внутреннего справочника, состояние и выбранные площадки. URL/телефоны/email вместо модели отклоняются; контакты продавцов и аккаунта не читаются для prompt. Произвольный текст модели не следует использовать для персональных данных. Результат LLM — только строгий JSON списка URL, лишние поля и неоднозначный JSON отвергаются. Если модель не заявляет JSON mode, применяется prompt + строгая серверная валидация без «ремонта» ответа.

Принимаются только точные URL из provider url_citation, HTTPS и домены/товарные пути существующей store_url-политики. CPU/GPU перепроверяются программными model_signatures, для GPU дополнительно VRAM, если она задана. Цитируемое название сохраняется отдельно. Цена/валюта/регион/состояние/продавец/доставка остаются null/unknown, если не подтверждены. Сниппет не является доказательством актуальной цены. Результат получает search_discovered и optimizer_eligible=false. StoreOffer и Hardware не создаются. Статус verified_current на основании AI никогда не присваивается.

Avito допускается только как ссылка на поисковую находку для перехода пользователя: отключённый прямой сбор не включается, объявления не импортируются. Для DNS/Citilink/Ozon/WB действуют те же границы. Дальнейшее чтение цены — существующий отдельный разрешённый pipeline с повторной проверкой, правами и отказом при антиботе.

## Задачи, кеш и бюджет

POST `/api/product-search` — явный запуск после входа, GET `/{id}` — только владелец, чужая задача 404. Ответы no-store. Очередь: один поток процесса, не более четырёх активных задач глобально в общей SQLite, пять новых задач пользователя/час. Нормализованный кеш на пользователя/модель/настройки провайдера — 10 минут; старые задачи удаляются через сутки, зависшие через пять минут завершаются как interrupted при обращении/новом запросе. После рестарта платный запрос не повторяется автоматически.

Бюджет резервируется BEGIN IMMEDIATE до сети: 20 запросов, 100000 зарезервированных токенов в сутки, денежный резерв по явному лимиту. До 20000 входных + max_output_tokens резервируются на попытку; это консервативная оценка, а не серверный token cap на скрытый контекст инструмента. Фактические usage учитываются отдельно. При неизвестных расходах fallback итог не показывает нулевую стоимость. 402 блокирует на сутки, 429 учитывает Retry-After (30–3600 секунд), три последовательных ошибки дают cooldown; успех сбрасывает счётчик. Максимум две настроенные модели, без бесконечных повторов.

SQLite координирует бюджеты только для процессов с одной и той же БД. Разные диски/реплики требуют внешнего общего хранилища/очереди. Redis не добавлен. Полной гарантии exactly-once внешнего биллинга нет; при падении неизвестная попытка остаётся зарезервированной.

Реальный поиск по Avito/DNS/Citilink/Ozon/WB в этой итерации **не тестировался**. Для каждой площадки импортировано 0 предложений и подтверждено 0 цен; это отсутствие запуска, не результат «товаров нет». Precision/recall, латентность поиска и стоимость успешной карточки пока неизвестны. Готовы мок-тесты протокола, ограничений, бюджета, владельцев и provenance.
