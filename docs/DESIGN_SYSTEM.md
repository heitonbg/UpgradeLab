# Дизайн-система UpgradeLab 2026

## Premium UI tokens и controls (2026-11-11)

Текущий источник палитры — `frontend/src/tokens.css`, общих controls и компоновки — `frontend/src/controls.css`. Главные поверхности: background `#101114`, surface `#17191f`, raised `#20232b`, input `#121419`; акцент сохранён `#7f98ff`. Для обычного input используется контрастная граница `#626a7c`. Актуальные контрастные значения и полный UX-аудит — в [PREMIUM_UI_UX_REVIEW.md](PREMIUM_UI_UX_REVIEW.md).

Новый `ui/Combobox` используется для игры, города, hardware search и фильтров: точное подтверждение опции отдельно от поискового текста, ограниченный список, keyboard interaction и портал, измеряющий viewport. `ui/Select` унифицирует оставшиеся нативные select по стилю и доступному имени. `Modal` имеет единый scroll owner и поддерживает вложенные порталы; `useConfirm` заменяет системные подтверждения в критичных пользовательских действиях.

Конструктор раскрывает редкие аппаратные ограничения по запросу и оставляет главными бюджет/назначение/цель/источники. Источники пользовательского UI — только Regard и биржа UpgradeLab. Представление результата разделяет наличие предложения, историю и подтверждение цены; unknown FPS — это «Нет данных». Это правила интерфейса, а не новые backend-права или алгоритмы.

Реализация: `frontend/src/tokens.css` (единственный источник цветов), `index.css` и `redesign.css`, согласованные Tailwind tokens и существующий набор ui-компонентов. Без сторонней UI/animation/chart библиотеки.

Эти значения относятся к текущим токенам, а не к каждому историческому CSS-селектору. Для текста поверх hero использована тёмная свободная область, на mobile — отдельная сплошная текстовая поверхность.

Button сохранён один: primary/secondary/outline/ghost/destructive (alias danger), iconOnly, disabled/loading и focus ring. Общие input/select/textarea, checkbox, segmented controls, modal и toast используют эти же tokens. Уведомления остаются role=status, ошибки role=alert. Существующая ловушка Tab/Escape модального окна и защита несохранённых изменений сохранены. Новые поля сортировки имеют явные accessible names; inline SVG расширены chart/pin вместо случайных символов.

PriceOriginBadge различает seller_declared/catalog_import/проверку карточки; заполненный verifiedAt не перебивает seller/catalog происхождение. CategoryImage — декоративная категория, а не фото SKU. Общий placeholder и onError фотографии не подставляют чужое исполнение товара.

## Компоновка

Горизонтальная sticky-навигация; до 800 px — две компактные строки с прокруткой navigation, основной контент не переполняется. Главная: hero + две асимметричные сценарные зоны + восемь категорий + линейное объяснение. Это не набор одинаковых рекламных карточек.

Конфигурация: компактные строки с изображением категории и ценовым evidence; справа sticky BuildSummary, на mobile — обычный доступный блок в потоке. Итоговая цена не названа актуальной при draft. Апгрейд сохраняет шаги ввода, отдельный анализ и результат; FpsComparison рисует только рассчитанные current/upgraded, без вымышленных игровых серий.

Поиск: отдельная страница, компактная форма географии/источников и строки предложений. Сортировка по цене, названию, свежести действует на полученные данные и не меняет серверный массив. Биржа: sidebar filters на desktop, компактная сетка на mobile; изображения contain, информация о продавце и доставке. Начальный DOM — 24 объявления, рабочее «Показать ещё» +24, фильтрация по всему полученному списку.

ListingForm: основные поля; раскрываемые характеристики/фото; явные доставка, цена, контакт; предварительный просмотр. Required validation открывает закрытую секцию, не оставляя невалидное скрытое поле без доступа. Авторизация/профиль используют общие поверхности; сохранённый результат выделяет историю, последние наблюдения и текущую подтверждённую цену отдельно.

Анимации ограничены короткими переходами; prefers-reduced-motion отключает движения. Никаких необоснованных светящихся декораций или фиктивных счётчиков.


## Унификация после UI-аудита (2026-11-10)

21 базовый цвет в tokens.css; HEX вне этого файла в основных CSS не добавлять. Для прозрачности — rgb(var(--*-rgb) / alpha), для Tailwind — ссылка на ту же переменную. Default: surface/input-surface; hover: surface-hover/accent-hover; active/selected: surface-selected; focus: accent + focus-ring; disabled: text-disabled/opacity; error/warning/success — одноимённые токены; loading — accent. Полная миграция и ограничения: UI_CONSISTENCY_AUDIT.md и UI_COLOR_MIGRATION.csv.

Кнопки/поля/select: высота 44 px, радиус 6 px; iconOnly 44×44. ErrorState — общий компонент для ошибок биржи/городов. Компактное описание не заменяет рабочий retry. Error нельзя представлять достоверным нулём: unknown — тире; empty — успешная пустая выдача; partial — прежние данные с предупреждением; refreshing — обновление без исчезновения старых карточек.

Sidebar биржи 300/280 px; до 800 px раскрывается кнопкой с aria-expanded. Типы объявлений: общая строка и две равные ячейки. На мобильных основные цели ≥44 px. Диалог ограничен 100dvh и прокручивается; поведение реальной экранной клавиатуры требует проверки на устройстве. Выбранный город не сбрасывается при сетевой ошибке.
