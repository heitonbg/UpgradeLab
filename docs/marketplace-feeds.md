# Предложения площадок и российских магазинов

В приложении реализованы поиск по публичной разметке, чтение ссылки на товар, браузерный поиск и получение JSON-выгрузок. В реестре 12 источников; [список, браузерный режим и результаты живой проверки](browser-price-search.md). Предложения сохраняются в SQLite (`store_offers`) с URL, ценой, временем и способом получения (`public_page`, `browser_page` или `feed`).

## Что работает без ключей

Раздел «Найти предложения…» выполняет серверный поиск на выбранных площадках. Адаптеры читают JSON-LD Product/Offer, известную разметку карточек и метаданные страниц товаров. Кнопка «Добавить предложение по ссылке» требует входа в обычный аккаунт. Адрес проверяется по домену и пути товара; сервер не переходит по редиректам.

Публичные сайты могут отвечать CAPTCHA, 401, 403, 429, требовать JavaScript или менять разметку. Приложение показывает недоступность каждого источника и не создаёт цену из поисковой ссылки. Это не гарантия непрерывного доступа. При проверке в этой среде все пять площадок ограничивали доступ хотя бы в одном запросе; ответ HTTP 200 у Яндекс Маркета также мог содержать CAPTCHA. Обход этих ограничений не реализован.

## Стабильное наполнение через выгрузки

Подключите полученную на разрешённых условиях выгрузку поставщика/партнёра либо свой сервис нормализации. Наличие Seller API-ключа само по себе не реализует поиск по всем продавцам: например, [Ozon описывает роли доступа к товарам продавца](https://dev.ozon.ru/start/300-Mapping-rolei-i-metodov-Seller-API/), а [метод цен Яндекс Маркета возвращает цены, установленные для товаров своего кабинета](https://www.yandex.ru/dev/market/partner-api/doc/ru/reference/prices/getDefaultPrices). Готового платного поставщика данных к проекту не подключено.

Есть два варианта подключения:

1. В `backend/.env` укажите `OFFERS_FEED_FILE=offers.json`. Файл читается при запуске. Для импорта без перезапуска из `backend` выполните `.venv/Scripts/python.exe -m scripts.import_offers offers.json`.
2. Укажите `OFFERS_FEED_URLS` — JSON-объект вида `{"ozon":"https://your-feed.example/ozon","avito":"https://your-feed.example/avito","wb":"https://your-feed.example/wb","yandex":"https://your-feed.example/yandex","dns":"https://your-feed.example/dns"}`. Для авторизации при необходимости задайте `OFFERS_FEED_TOKENS={"ozon":"your-secret"}`. Сервер отправляет GET с параметрами `query` и `category`; токен отправляется только соответствующему настроенному endpoint в заголовке Bearer. Endpoint должен сразу вернуть JSON без редиректа. Токены хранятся только в окружении сервера.

Нормализованный ответ — объект `{"offers": [...]}`. Пустой шаблон находится в `backend/offers.example.json`. Тестовые цены из тестов не загружаются в рабочую базу. Пример строки ниже иллюстрирует формат; цена, ссылка и дата должны быть заменены реальным наблюдением:

```json
{
  "source": "ozon",
  "category": "CPU",
  "name": "AMD Ryzen 5 5600",
  "model_name": "AMD Ryzen 5 5600",
  "price_rub": 10000,
  "url": "https://www.ozon.ru/product/replace-with-real-product-123/",
  "condition": "new",
  "observed_at": "2026-10-27T10:00:00Z",
  "attributes": {}
}
```

`source`: `ozon`, `avito`, `wb`, `yandex`, `dns`, `citilink`, `regard`, `oldi`, `kns`, `xcom`, `onlinetrade`, `nix`. `category`: `CPU`, `GPU`, `motherboard`, `memory`, `storage`, `psu`, `case`, `cooler`. Цена — положительное целое число рублей. `condition` — `new` или `used` (для Avito). Время — фактическое время наблюдения, а не импорта. Будущие даты не принимаются. Ссылка должна вести на товар соответствующей площадки, а не на поиск.

`model_name` необязателен. Он помогает однозначно связать CPU/GPU с каталогом производительности. Несовпадающие суффиксы (`5600`/`5600X`, `Ti`, `XT`), неоднозначная модель и различия указанного VRAM не должны превращаться в одну модель. Несопоставленное предложение показывается в поиске, но не используется в расчёте FPS. Названия аксессуаров, комплектов и системных блоков исключаются из такого сопоставления.

Поставщик должен передавать доступные к покупке товары. Необязательное поле `available: false` удаляет ранее сохранённое предложение с тем же URL, если наблюдение не старше сохранённого. Простое отсутствие строки в частичной поисковой выдаче не означает, что товар снят с продажи; такие старые наблюдения исключаются через 24 часа.

Для автоматического выбора остальных деталей нужны `attributes`:

| Категория | Обязательные для автоматического подбора параметры |
| --- | --- |
| `motherboard` | `socket`, `ram_type`, `form_factor` (`ATX`, `mATX`, `Mini-ITX`) |
| `memory` | `ram_type`, `capacity_gb` (не меньше запрошенного), `modules` (2) |
| `storage` | `interface` (`SATA`), `capacity_gb` (от 480) |
| `psu` | `watts` (от 650), `form_factor` (`ATX`) |
| `case` | `board_formats` (список поддерживаемых форм-факторов платы), `psu_formats` (включая `ATX`) |
| `cooler` | `sockets` (список поддерживаемых сокетов) |

Это базовые фильтры MVP. Запас мощности БП под конкретные CPU/GPU, питание видеокарты, высота кулера, длина GPU, SATA-порты/кабели и BIOS требуют отдельной проверки. Отсутствующие характеристики не угадываются: для автоматической сборки такой товар не подходит. При ручном выборе предложения проверяются имеющиеся параметры сокета, RAM и кулера; неизвестные остаются предметом ручной проверки.

## Как цены участвуют в подборе

Предложения действуют 24 часа. Среди выбранных площадок для каждой однозначно сопоставленной модели CPU/GPU выбирается минимальная доступная цена. Для целевого FPS выбирается самая дешёвая подходящая пара, а если цель недостижима — максимальный FPS в бюджете. В автоматическом режиме стоимость остальных деталей резервируется до подбора пары.

Режим «Все доступные, включая архив» также разрешает старые источники PassMark/Avito с их прежними сроками действия. Режим «Предложения выбранных площадок» исключает их: отсутствие котировок выбранного магазина не заменяется ценой PassMark. Доставка, регион, скидка по карте и персональные предложения не включены в расчёт.

При выборе конкретного предложения его ID отправляется серверу. Цена и название повторно читаются из БД; присланная браузером цена не может подменить цену предложения. Просроченные предложения отклоняются. Сохранённая сборка остаётся историческим результатом со ссылками и датами; новое сохранение/расчёт повторно проверяет актуальность.

Поиск кэшируется на 10 минут, сетевые запросы ограничены по времени и размеру ответа. При изменении выгрузки повторите запрос после истечения кэша либо используйте новый запрос. `OFFERS_LIVE_SEARCH=false` отключает запросы публичных страниц; локальные предложения и настроенные endpoint-выгрузки продолжают работать.
