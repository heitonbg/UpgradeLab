## 2026-11-12 — Optimizer V2 implementation

Исправлены три конкретных отсечения/ранжирования автоматической сборки. FPS перестал быть objective-score и условием target attainment в automatic gaming path: `target_reached=null`, FPS оставлен отдельно как legacy estimate. Hardware proxy использует empirical catalog percentile CPU Mark/G3D и геометрическое объединение с RAM capacity/module proxy; balanced максимизирует weakest-link score (минимум CPU/GPU/RAM percentiles), performance максимизирует геометрический proxy, economy выбирает минимальную полную цену. У RAM скорость — только tie-breaker, channel status — potential при поддержке платы, FPS bonus отсутствует. Ручной и старый assembly path сохраняют прежний target contract. Это проверяемая эвристика, не доказательство game FPS.

Добавлены малые exhaustive objective oracle и RAM/quantity regressions. На изолированной копии SQLite повторено 25 API сборок по прежним профилям; время и every before/after row — [OPTIMIZER_V2_IMPLEMENTATION.md](OPTIMIZER_V2_IMPLEMENTATION.md), локальный response artifact — `.artifacts/product-readiness-20261111/gaming-matrix-v2.json`.
