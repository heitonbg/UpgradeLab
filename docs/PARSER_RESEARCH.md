Дата: 2026-11-09. Стадия 1 завершена до реализации. Исследован текущий HEAD основной ветки каждого из 9 публичных репозиториев; это не аудит всех веток/всей истории. Ни сторонний код, ни его тесты/установщики не запускались. Исходники изолированы в .research/parser-sources и исключены из Git. Новых зависимостей нет. Магазины, cookies, прокси и внешние сервисы конвертации URL не запрашивались.

Воспроизводимость: [manifest](parser_research_manifest.json) фиксирует полный commit SHA, дату commit и SHA-256 файлов доказательств. Дата ниже — дата последнего commit просмотренной ветки, а не гарантия работоспособности или дата live-проверки. Ссылки файлов в подробном перечне строятся через этот commit.

Метки: **Код** — наблюдаемая реализация; **README** — заявление автора; **Вывод** — оценка применимости. Наличие теста означает, что он изучен, а не что мы его запускали.

## 3. Карта «источник → транспорт → формат → извлечение → нормализация → сохранение»

- **Ситилинк / strupeiq:** native Playwright → DOM категорий/товара → локальные selectors → strip/int → SQLModel current row → NATS event. Ошибка одной карточки теряется в except. Пагинация задана числом страниц; фоновые tasks используют переданную DB session, что не подходит текущему правилу UpgradeLab «workers без общей сессии».
- **Avito / Duff89:** URL/config location → сторонний URL converter и curl_cffi с cookies → private JSON/initialData → Pydantic Item + AdsFilter → SQLite viewed/Excel/notifier. IP/session recovery и внешняя выдача cookies не переносятся. None→0 допустим как технический sentinel seen-table автора, но не как цена.
- **Avito / domovoy:** URL pages → HTTP либо browser → JSON hydration/DOM → nullable AvitoItem → ItemsRepository/price_history. extract_page сначала отсекает challenge; неизвестная разметка отличается от явной пустоты. exhaustive=False предотвращает вывод «удалено» только из ограниченной выдачи. При полном delete история тоже удаляется: не брать это поведение для исторических сборок UpgradeLab.
- **DNS / HecyMa:** browser category/page → characteristics+reviews HTML → BS4 dict → required-key check → Mongo → Parquet → Dask/ML. Это аналитический pipeline, не надёжный API предложения с UTC/TTL. Парсер может вернуть error dict, а отзывы — пустой список после ошибки.
- **DNS / kireev20000:** browser category → characteristics HTML → BS4 selectors → text/int → pickle+Excel. Не загружать чужой pickle; нет независимой price verification, region/TTL или durable worker.
- **WB/Ozon/Яндекс/Ситилинк / Grex:** Registry → site crawler → HTTP/internal JSON/JSON-LD/Next.js/browser → ProductCard → Product/PriceSnapshot/alerts. Batch semaphore и измерение времени полезны, но инфраструктура Redis/новая панель UpgradeLab не нужна.
- **WB/Ozon / MaxDev43:** browser bootstrap/session → внутренние API → widgets/card JSON → common clean_text/price → JSON output, basket cache. Не переносить bootstrap, подмену браузерных признаков, auto-download или guessed basket-host probing.
- **Ozon/WB/Яндекс / remzone:** browser → disk HTML snapshots → ParserService BS4 → JSON для UI. Разделение raw snapshot/extractor полезно, но глобальные очищаемые папки не изолируют конкурентные задания, а sorted price blocks не устанавливают условия цены.
- **ru-marketplace-mcp, шесть целевых коннекторов:** source registry → paced HTTP/CDP → internal JSON/DOM/JSON-LD → nullable output models+identity/shape checks → TTL cache+MCP response. Полезны код ошибки, warnings и тесты инвариантов, не CDP/TLS impersonation. Region из URL/session не равен подтверждению доставки выбранного SKU.

Для всех 12: есть контрактные 12×4 синтетические JSON-LD сценарии и общие SSRF/UTC/price tests; это не fixtures текущего реального сайта. Цена подтверждается отдельной карточкой, а не новым cached_at. Повторная проверка не требует нового транспорта. Кеш поиска 10 минут, проверка страницы менее 15 минут, наблюдения 24 часа; изменения этих правил не обоснованы. Отсутствие live-проверки не доказывает неисправность.

Дублирование: единый парсер уже снижает копипасту магазинов; HTTP/browser/discovery/feeds имеют разные result/error envelopes, а status смешивает происхождение и исход. Не создавать 12 новых сетевых клиентов. В существующем collect_source нельзя отделить HTTP 429, block и неузнанный документ стабильным машинным кодом; это подтверждённая архитектурная задача без внешнего разрешения.

## 6. Что переносить и что исключить

**Идеи для собственной реализации:** provider-neutral outcome; сохранение partial результата; признаки явной пустоты vs нераспознанного документа; nullable цена; exact model+variant checks; структурный drift-fixture; per-source elapsed time; отдельные observed/verified/attempted timestamps; append-only наблюдения при доказанной необходимости, identity по source+offer.

**Не переносить:** сторонний HTTP вместо SafeSession, TLS impersonation, cookie-farm/session recovery, proxy rotation, WAF/CAPTCHA обход, CDP в неизолированной сети, автоматическую установку браузера, unknown→0, «минимальная цена на странице», использование private API без договора, привязку произвольного DEST к своему city_id, удаление истории из-за неполной выдачи. Логи raw HTML/cookies/config не копировать.

Код из репозиториев не перенесён. MIT не использована как основание для доступа к магазинам. План — [SOURCE_ARCHITECTURE_PLAN.md](SOURCE_ARCHITECTURE_PLAN.md).
