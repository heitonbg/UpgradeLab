# FPS Engine V3: текущий статус

Дата: 2026-11-12.

- Лицензированный набор содержит 81 измерение, 4 игры, 3 CPU, 3 GPU и 4 тестовые серии. Офлайн-агрегация даёт 72 строгие когорты; ни одна не имеет двух независимых издателей. Обновлённый полный Open GPU API не добавил новых допустимых игровых прогонов. Открытый набор FPSHQ community на дату проверки содержит 0 строк; медианы смешивают измерения и перерасчёты обзоров.
- Проверенные данные остаются с URL, лицензией, серией и исходными настройками. Неизвестные настройки не приписываются. Синтетические тесты и чужие FPS-калькуляторы не попадают в `measured`.
- Существующий legacy FPS показывается отдельно как эвристическая оценка. Hardware proxy оптимизатора не является FPS. Достижение целевого FPS для автосборки остаётся неизвестным без сопоставимых измерений.
- Массовый импорт возможен только после подтверждения лицензии, исходных серий и полного набора условий. Текущая выборка не позволяет доказать улучшение независимым holdout, поэтому ML/нейросеть не обучена и не включена в production.
