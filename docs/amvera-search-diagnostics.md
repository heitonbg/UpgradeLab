# Поиск на Amvera: проверка и ограничения

Весь поиск выполняется backend на Amvera. Компьютер или телефон посетителя в сборе предложений не участвует. Локальный агент не требуется.

## Проверка развёрнутого backend 5 ноября 2026

Адрес: https://backendupgradelab-iwrawww.waw0.amvera.tech

Проверены `/api/health`, `/api/offers/status` и поиск `RTX 3060` через `/api/offers/search`.

| Источник | Фактический ответ в этой проверке |
| --- | --- |
| Avito, HTTP | HTTP 429 |
| Avito, браузер | CAPTCHA или запрет доступа; Bing не дал ссылок на объявления; 0 предложений |
| Регард | Страница получена; возвращены предложения |
| KNS | Страница получена; возвращены 10 предложений |
| DNS | HTTP 401 |
| Ситилинк | HTTP 429 |
| Ozon | Цикл перенаправлений |
| XCOM-SHOP | На странице не найдены читаемые карточки с ценой |
| WB, Яндекс Маркет, OLDI, ОНЛАЙН ТРЕЙД, НИКС | Общая ошибка чтения источника; точная причина старой версией API не раскрывается |

Это один диагностический запрос, а не гарантия состояния всего каталога. Поле `fresh_offers` считает сохранённые предложения за последние сутки: оно не подтверждает доступность поиска прямо сейчас. Возвращённые поиском предложения также могут включать сохранённые наблюдения. После обновления `last_search` в `/api/offers/status` показывает последний сохранённый ответ каждой площадки и время проверки.

## Изменения для следующего развёртывания

- HTTP-запрос сохраняет cookies в течение цепочки перенаправлений. Проверка домена при перенаправлении и запрет пересылки токена сохранены.
- Если выбранный поисковик не дал ссылок, браузер пробует другие поисковики: Bing, Яндекс, Google. Цена проверяется на странице товара, а не берётся из поискового описания.
- Поиск получает общий лимит сетевых операций 45 секунд; отдельное чтение товара браузером — 20 секунд. Это лимит сетевых попыток, а не гарантия времени ответа под нагрузкой.
- Браузер не загружает изображения, видео и шрифты, чтобы уменьшить расход ресурсов.
- При резервном поиске браузер открывает поиск самих магазинов и затем использует поисковики. Ранее эта стадия пропускала поиск магазина и обращалась только к поисковику.
- В очереди HTTP-попыток первыми идут Регард и KNS. Уже отказавшие браузерные источники не занимают повторно место в очереди.
- HTTP-ошибки и сетевые тайм-ауты различаются в отчёте. Неверно классифицированные аксессуары корпуса исключаются также из сохранённых предложений.

Эти изменения нужно загрузить в backend-приложение Amvera и пересобрать контейнер. Они не меняют уже запущенный контейнер автоматически.

## Проверка после обновления

В PowerShell:

```powershell
$api = 'https://backendupgradelab-iwrawww.waw0.amvera.tech'
Invoke-RestMethod "$api/api/health"
(Invoke-RestMethod "$api/api/offers/status").sources | Select-Object source, fresh_offers, last_search
$body = @{ query = 'RTX 3060'; category = 'GPU'; sources = @('regard', 'kns'); method = 'http' } | ConvertTo-Json
Invoke-RestMethod "$api/api/offers/search" -Method Post -ContentType 'application/json' -Body $body
```

Для единичной проверки Avito замените `sources` на `@('avito')`. После HTTP 429 или CAPTCHA не запускайте частые повторные проверки: они не подтверждают восстановление доступа и могут продлить ограничение. В backend уже предусмотрена пауза HTTP-запросов к отказавшему источнику.

Если сама страница Avito продолжает возвращать CAPTCHA, увеличение тарифа или смена устройства посетителя не обеспечивает доступ. Для гарантированного канала данных требуется разрешённая интеграция или источник предложений с подходящим доступом. Настройка `OFFERS_FEED_URLS` подключает такой источник, но сама по себе не создаёт доступ к Avito. Наличие публичного API для любых чужих объявлений здесь не предполагается.

Текущая версия использует только публичные страницы и поиск без сторонних платных API. Интеграция с платным провайдером удалена по требованию пользователя; зоны в его аккаунте созданы не были. Устройство посетителя не используется как агент сбора. Подробности — [бесплатный поиск](free-search.md).

## Диагностика апгрейда 5600X + RTX 5060

Повторная проверка работающего backend: CS2, Low, 32 ГБ DDR4, цель 550 FPS, бюджет 20 000 ₽ с продажей CPU.

- Расчёт без нового поиска вернул HTTP 200: 406 → 428 FPS, Ryzen 7 5700X за 14 850 ₽ из Регарда. Продажа 5600X оценена в 10 550 ₽ по 29 сохранённым объявлениям Avito; общий бюджет 30 550 ₽. Цен X3D в ответе каталога не было.
- Прямой HTTP-поиск Avito возвращал 403. Отдельный поиск через поисковики на Amvera завершился за 24,6 секунды без ссылок; у всех четырёх поисковиков сохранён тайм-аут. В предыдущей попытке сохранена общая ошибка запуска браузера.
- Найденные ошибки кода: выбор двух CPU по близости синтетического балла пропускал X3D; розничная цена отменяла резервный поиск Avito; для автоматической продажи резервный поиск был привязан к CPU даже при ограничении GPU; после тайм-аута навигации уже отображённая выдача могла отбрасываться; варианты без цены скрывались, если существовала хотя бы одна доступная по цене замена.
- В новой версии исправлены эти пути, добавлены диагностика установки браузера, контейнерный запуск Chromium и статусы обновления цен в интерфейсе. Проверка на сохранённых данных полного каталога оставляет X3D в сравнении с неизвестной ценой. Числа не заменяются выдуманными рыночными оценками, 550 FPS не объявляются достигнутыми.

Изменения проверены локально. На Amvera они появятся после загрузки обновлённых папок backend/frontend и пересборки. Текущая блокировка Avito не считается устранённой только на основании исправления кода.

## Живая проверка серверных задач, 5 ноября 2026

На backend подтверждена версия `server-jobs-http-v1`, Linux, Playwright 1.64.1 и наличие полного Chromium. Запуски обоих поисков вернули 202 за 0,34–0,39 с; опрос состояния и получение результатов прошли без обрыва. Сборка за 50 000 ₽ вернула частичный результат из семи категорий; апгрейд повторил 5700X за 14 850 ₽ без новых цен X3D. Это не считается успешной проверкой полноты подбора.

Отдельный запрос SSD с самого backend получил Netac NV3000-Q 512 ГБ за 9 650 ₽ и NV3000 500 ГБ за 10 050 ₽. В частичном плане сумма остальных семи позиций была 42 183 ₽, остаток 7 817 ₽: найденные SSD не помещались в этот остаток. Поэтому надпись «не найдено» скрывала также проблему бюджета. В плане присутствовала плата H610 под Intel вместе с Ryzen и пометкой «из ремонта»; такой результат исключён в следующей версии.

HTTP-выдача Google и Яндекса в сохранённых статусах не читалась из-за запрета всех перенаправлений при отсутствии магазина. Версия v2 разрешает переходы только между фиксированными доменами соответствующего поисковика. В ней также исправлены категория похожих товаров, совместимость частичного плана, фильтрация восстановленных плат, приоритет недостающих категорий и группировка записей в SQLite. Прогресс записывается с ограниченной частотой; после сетевого срока новые стадии не запускаются. Интерфейс различает отсутствие предложений и найденные цены вне оставшегося бюджета.

В диагностике полного Chromium проверялся один исполняемый файл, но `channel=None` выбирал отдельный headless-shell. В v2 на Linux задан `channel='chromium'`; диагностический ответ сохраняет конкретную последнюю ошибку запуска и доступные лимиты памяти/PID контейнера. Документация Playwright о различии сборок: https://playwright.dev/python/docs/browsers.

Маркер следующей версии: `server-jobs-http-v2`. Её работу на Amvera необходимо проверить после пересборки; локальные тесты и наличие файла браузера не подтверждают получение новых объявлений Avito.
