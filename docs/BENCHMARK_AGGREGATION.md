# Benchmark Aggregation: строгие игровые когорты

Дата: 2026-11-12. Офлайн-конвейер: `backend/app/services/benchmark_data.py` валидирует и сохраняет исходные публикации, `backend/app/services/benchmark_aggregation.py` группирует уже подготовленные `measured` записи; `backend/scripts/aggregate_fps_benchmarks.py` воспроизводимо записывает `backend/app/data/benchmarks/aggregates.json`. Пользовательский запрос не запускает импорт или агрегацию.

## Правила

- Вход проходит `Observation` с проверкой FPS, лицензии CC BY 4.0 и URL происхождения. `estimated` исключаются. Повторный ID отвергается; прежняя дедупликация источника выполняется до агрегации.
- CPU и GPU сравниваются после нормализации регистра и пробелов. Иные алиасы требуют отдельной проверенной таблицы соответствий; не объединяются автоматически.
- Ключ включает игру и версию, точные CPU/GPU, объём/тип/каналы RAM, разрешение, preset, RT, upscaling, FG и режим, render scale, сцену, разгон, ОС, форм-фактор и профиль питания. `null` сохраняется и не равен известному значению. Неизвестные настройки не подменяются типичными.
- Повторы одной пары `(publisher, series_id)` сначала сводятся в одно среднее. Затем серии усредняются по издателю, а издатели получают равный вес. 1000 повторов или серий одного издателя не подавляют пять независимых издателей.
- Выводит mean, median, P10/P90 **между средними независимых издателей**, стандартное отклонение, MAD, число наблюдений, серий, издателей, ссылки и отметку ограниченности. Эти P10/P90 не являются игровым 1% Low. При отсутствии единого документированного метода захвата frametime агрегат `one_percent_low_fps` остаётся `null`.
- Сырые измерения остаются в `measurements.json`. Сводка не повышает достоверность исходных данных автоматически.

## Фактическое покрытие

На текущем лицензированном наборе: 81 наблюдение → 72 строгие когорты; когорт с двумя независимыми издателями — 0. Большое число опубликованных прогонов одного оборудования не решает проблему переносимости на другие CPU/GPU и игры. Офлайн статистика пока не применяется как подтверждённый FPS для широкого подбора.

Источник: [Open GPU Benchmarks](https://opengpubenchmarks.com/license/) разрешает повторное использование и обучение с атрибуцией; [TechFuelHQ](https://techfuelhq.com/data/) даёт отдельные опубликованные точки. Официальный полный Open GPU JSON на дату проверки содержал 93 записи, включая уже учтённые 73 игровых прогона и 20 синтетических; community JSON — одну синтетическую запись. Новых пригодных измерений из этих двух файлов не добавлено. Для OpenBenchmarking и обзоров издательств права на массовый импорт игровых данных не подтверждены. FPSHQ публикует также оценки и агрегаты; его открытая выгрузка community-замеров на 2026-11-12 содержит 0 строк, а 195 медианных FPS смешивают независимые измерения с пересчётом обзорных таблиц. Поэтому они не импортируются как индивидуальные `measured`. Подробный реестр источников: [FPS_BENCHMARK_DATA.md](FPS_BENCHMARK_DATA.md).

## Проверка

`python -m unittest backend.tests.test_benchmark_aggregation` проверяет независимость серий, разделение известных/неизвестных условий, исключение оценочных FPS и отказ от невалидных записей. `PYTHONPATH=backend python backend/scripts/aggregate_fps_benchmarks.py` воспроизводит агрегаты. Нейросеть не обучена: независимых аппаратных связок и серий для надёжного holdout недостаточно.
