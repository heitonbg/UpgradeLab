# Поиск цен через магазины и браузер

Реестр включает 12 источников: Ozon, Avito, WB, Яндекс Маркет, DNS, Ситилинк, Регард, OLDI, KNS, XCOM-SHOP, ОНЛАЙН ТРЕЙД и НИКС. Это список проверяемых источников, а не гарантия доступа ко всем магазинам России.

В конфигураторе раскройте «Найти предложения на площадках и в российских магазинах», укажите модель (`RTX 5060`), категорию GPU и способ поиска:

- **Быстрый поиск** читает публичную разметку; можно выбрать все источники.
- **Браузер: магазин, затем поиск карточек** загружает магазин через Edge/Chromium и выполняет JavaScript. Если выдача не читается, ищет ссылки на товары через поисковик и проверяет страницы товаров.
- **Поисковая строка → карточки магазинов** сначала находит ссылки в поисковике, затем читает цену на площадке.

Для браузерного поиска выберите до трёх площадок за запрос. Одновременно используются не больше двух изолированных контекстов. Поиск может занять минуту или больше. Автоматическое решение CAPTCHA, смена IP и использование личного браузерного профиля не реализованы.

Цена поискового сниппета никогда не участвует в бюджете. Ссылки с непроверенной ценой показываются отдельно. В форме «Добавить предложение по ссылке» также можно выбрать браузерное чтение товара (после входа).

Из CPU/GPU-выдачи исключаются распознанные готовые ПК, ноутбуки и аксессуары. `RTX 5060` и `RTX 5060 Ti` различаются. Несопоставленные модели не получают чужой прогноз FPS. SoldOut/OutOfStock и «последняя цена» не считаются доступным предложением.

## Живая проверка 27 октября 2026

| Источник | Прямое чтение | Браузер |
| --- | --- | --- |
| Регард | Товары и цены из OfferCatalog | В отдельном запросе 403 |
| OLDI | Карточки и цены | Карточки и цены |
| KNS | Product/Offer microdata с ценой и наличием | В отдельном запросе проверка доступа |
| DNS | HTTP 401 | Запрет доступа/403 |
| Avito | HTTP 429 | Проверка безопасности/439 |
| Ситилинк | HTTP 429 | Выдача без читаемых цен |
| XCOM-SHOP | Нет читаемых карточек | Страница загрузилась, цены не извлечены |
| ОНЛАЙН ТРЕЙД | Нет читаемых карточек | Не подтверждено |
| НИКС | Публичная форма поиска возвращает URL выдачи, данные загружаются дополнительно | Не подтверждено |
| Ozon, WB, Яндекс Маркет | Ранее возвращали ограничение доступа/CAPTCHA | Не подтверждено |

После фильтрации получено 28 предложений видеокарт RTX 5060 от KNS, Регард и OLDI. Они сохранены в рабочей БД с датами, ценами и ссылками. Отчёт: `.artifacts/rtx5060-verified.json`; браузерный отчёт OLDI: `.artifacts/rtx5060-oldi-browser.json`. Количество и цены относятся к этой проверке, они меняются.

## Установка

Из `backend` выполните:

```powershell
uv pip install --python .venv/Scripts/python.exe -r requirements-browser.txt
```

По умолчанию используется установленный Edge (`OFFERS_BROWSER_CHANNEL=msedge`); Playwright поддерживает его через [channel](https://playwright.dev/python/docs/browsers#google-chrome--microsoft-edge). Если Edge отсутствует, выполните `.venv/Scripts/python.exe -m playwright install chromium` и задайте пустой `OFFERS_BROWSER_CHANNEL=`.

```dotenv
OFFERS_BROWSER_ENABLED=true
OFFERS_BROWSER_CHANNEL=msedge
OFFERS_BROWSER_CDP_URL=
OFFERS_BROWSER_TIMEOUT_MS=12000
OFFERS_BROWSER_PRODUCT_LIMIT=3
OFFERS_BROWSER_SEARCH_ENGINE=bing
```

Поисковая система — `bing`, `google` или `yandex`; она также может запросить проверку. Для уже запущенного **отдельного** браузера можно задать `OFFERS_BROWSER_CDP_URL=http://127.0.0.1:9225` ([connect_over_cdp](https://playwright.dev/python/docs/api/class-browsertype#browser-type-connect-over-cdp)). Разрешены только localhost-адреса. Не публикуйте DevTools-порт наружу. Сбор использует отдельные контексты без авторизованных личных сеансов.

Разные способы и поисковые системы имеют раздельный кэш на 10 минут. Если новая проверка не удалась, старые свежие котировки могут показываться с прежней датой и способом получения: они не становятся браузерными котировками автоматически.

## Командная строка

```powershell
.venv/Scripts/python.exe -m scripts.collect_offers --list-sources
.venv/Scripts/python.exe -m scripts.collect_offers "RTX 5060" --sources regard oldi kns --method http --report ../.artifacts/offers.json
.venv/Scripts/python.exe -m scripts.collect_offers "RTX 5060" --sources dns avito --method browser
.venv/Scripts/python.exe -m scripts.collect_offers "RTX 5060" --sources dns --method discovery
```

Реестр и пути товаров находятся в `backend/app/core/stores.py`. При добавлении источника обновляются тип `Source`, ограничения числа источников в схемах расчёта и список `STORES` интерфейса. HTTP-редиректы разрешены только внутри магазина; токены endpoint-выгрузок не пересылаются по редиректам. Серверу нужен сетевой доступ к площадкам и браузеру.

Нормализованные выгрузки совместимы с браузерными котировками: [формат и подключение](marketplace-feeds.md). Для недоступных источников они остаются альтернативным способом получения цен.
