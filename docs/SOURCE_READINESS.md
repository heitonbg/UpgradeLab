# Источники UpgradeLab после SSRF-защиты — итерация 5

Дата: 2026-11-09. Это аудит фактического кода и локальная регрессия. Доступность всех 12 сайтов **не проверялась live**: подтверждений права на автоматический сбор для UpgradeLab нет. Статус «Не проверялся» не означает ни доступность, ни запрет площадки. Отсутствие найденной документации не доказывает отсутствие API.

## Реализация и матрица

Все источники описаны в backend/app/core/stores.py. Общие адаптеры: store_providers.search_public/parse_html (HTTP, JSON-LD, CSS-карточки, microdata, OpenGraph); public_discovery.discover_public_offers (HTTP-поисковики → проверка конкретной страницы); browser_offers (Chromium/CDP запрещён до изоляции). offers.collect_source принимает настроенный JSON-feed для каждого источника в HTTP-режиме; load_offer_file импортирует JSON. Специальных официальных API-клиентов площадок сейчас нет. НИКС дополнительно использует POST поиска FastSearch; это форма сайта, не подтверждённый официальный API.

Обозначения: **H** — общий HTTP-парсер; **W** — HTTP discovery; **F** — общий JSON-feed/импорт, требующий согласованных данных; **B-off** — browser/discovery с native Chromium недоступны. **L4** — 4 синтетических JSON-LD сценария CPU/GPU/RAM/плата через SafeSession с моками DNS и ответа. Это 48 subtests, не сохранённые ответы реальных сайтов. NIX resolver в L4 подменяется; POST проверяет отдельный test_safe_http. W отдельно проверен существующими test_public_discovery/test_browser_offers. F проверен локальным тестом без live-search/браузера. B-off проверен для всех 12.

CSS-селекторы показывают намерение адаптера, а не наличие этих элементов в сегодняшнем ответе сайта. У всех H есть независимый путь JSON-LD. Требуется ли JS на актуальной странице каждой площадки, без разрешённой live-проверки установить нельзя. Все 12 утратили именно browser/discovery режим; нельзя утверждать, что каждый источник целиком перестал работать. Успешно разобранная поисковая страница не подтверждает цену товарной страницы.

## Проверенные регрессии и исправления

1. Новый SafeResponse принудительно заменял явно указанные ISO-8859-1/ASCII на UTF-8. Это подтверждённая регрессия контракта декодирования; тест с single-byte ответом падал до исправления. Теперь заявленный charset соблюдается; UTF-8 остаётся fallback при отсутствии/неизвестной кодировке. На реальном магазине этот дефект не воспроизводился.
2. Интерфейс продолжал предлагать browser/discovery и обещать исполнение JS после отключения Chromium. Эти варианты убраны, доступен безопасный HTTP web discovery. Импорт browser по API возвращает 503 с конкретной причиной изоляции вместо общего сообщения о блокировке площадки.
3. Поисковая выдача не сообщала, что статусы взяты из кеша, и не выделяла частичный результат. Добавлены search_cached, unavailable_sources, partial_result. Тест кешированной ошибки сначала падал. Это существовавший пробел диагностики, а не доказанная поломка DNS pinning.
4. Текст «Цены действуют 24 часа» создавал неверную гарантию. Теперь разделены срок наблюдения и подтверждение страницы менее 15 минут. UI показывает дату наблюдения и наличие свежего подтверждения.
5. /offers/status явно сообщает live_status=not_checked, отдельно от последнего конкретного поиска. Настроенный feed не объявляется рабочим или разрешённым.

Нормальные HTTPS/redirect/Host/SNI/cookie сценарии покрыты test_safe_http. Сетевые правила, публичность DNS, pinning, TLS verification и лимиты не ослаблялись. Других доказанных регрессий сетевого транспорта не обнаружено.

## Ошибки и пользовательские сценарии

collect_source различает timeout/unavailable/disabled и сохраняет причину. 403/429/CAPTCHA не превращаются в успешный пустой каталог; cooldown действует 10 минут. Отсутствие читаемой разметки означает неизвестность (JS/изменение страницы), а не отсутствие товара в продаже. Ошибка одного магазина не отбрасывает другие; можно изменить выбранные источники. Старое наблюдение не получает нового price_verified_at только из-за нового поиска или выдачи кеша.

Фиксированные сценарии в полной регрессии:
- CPU/GPU/RAM/плата, названия/цены: test_source_readiness, 48 сочетаний.
- Соответствие модели: новый тест RTX 4060 против Ti и test_offer_safety/test_browser_offers.
- Актуальность/повторная сверка/изменившаяся цена: test_price_time, test_price_verification и test_safe_http.
- Апгрейд, выбранные магазины, полный бюджет и сохранение: test_upgrade_recommendations, test_platform_upgrade, test_build_variants, test_automatic_policy, standalone smoke/recovery.
- Один и несколько магазинов, сбой одного: test_free_search/test_upgrade_recommendations; новый тест кешированной ошибки двух источников.
- Недоступные источники: test_search_outages сохраняет честный draft или partial без придуманного итога.
- complete/draft/partial: существующие price_time/adaptive/build_variants/outages tests; сроки TTL и переходы состояний не менялись.
- Настроенный feed работает без Playwright/live-search; товарные страницы и сеть в этих тестах заменены фикстурами.

Рабочая SQLite-база не менялась; тесты используют временные/памятные базы. Проверка реальных магазинов, DNS/TLS и условий сети Amvera не проводилась. Нет оснований заявлять хотя бы один источник «Работает live».
