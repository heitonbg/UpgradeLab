# Gaming Optimizer V3: реализация и проверка

Дата: 2026-11-12. Изолированная staging SQLite: `.artifacts/product-readiness-20261111/pc_upgrade_v3.db`, копия ранее подготовленного каталога Регарда. Сеть магазинов, импорт и платные поисковые сервисы при расчётах выключены. Рабочая БД не изменялась.

## Причины и изменения

- Автоматический интерфейс предлагал Balanced/Economy/Performance; теперь отправляет `objective=performance` как внутреннее обозначение цели `maximum_performance`. Старые значения API остаются совместимыми с сохранёнными сборками. Заголовок основного варианта соответствует игровой задаче.
- V2 ранжировал Performance по геометрическому среднему percentile CPU Mark, GPU G3D и RAM. Многопоточный CPU Mark мог поднять Ryzen 9 5950X выше лучшей игровой связки. V3 сначала максимизирует слабейший аппаратный percentile CPU/GPU/RAM, затем привязанный к сценарию показатель: CPU для CS2 1080p Low, GPU для более тяжёлых пресетов. Это ограниченный аппаратный прокси, не измеренный FPS.
- Для AM4/AM5 при известном числе ядер CPU percentile консервативно ограничен минимумом percentile общего CPU Mark и CPU Mark на заявленное ядро. Второй показатель не выдаётся за Single Thread. У Intel поле `cores` неоднородно для P/E-ядер, поэтому та же коррекция не используется; сравнение разных платформ остаётся ограничением.
- Существующие проверки совместимости CPU/платы, SSD/слота, PSU, кулера, бюджета всех восьми деталей и physical fit остаются в поиске. Для повторных CPU/GPU-пар допустимые базовые сборки индексируются по стоимости и отсекаются через bisect; глобальный оптимум не заявляется.
- SSD shortlist сохраняет недоминируемые цены/ёмкости/SATA/NVMe по источникам. Долю бюджета на SSD не применяют до проверки полной стоимости. 1 ТБ NVMe допускается, если цена за ГБ не хуже дешёвого кандидата более чем на 10%; 2 ТБ дополнительно требует доплаты не выше 5% общего бюджета. Это ограничение выбора накопителя, не ограничение совместимости. NVMe допускается лишь при подтверждённом M.2 2280 PCIe/NVMe. Числа чтения/записи и DRAM не добавлены без источника.
- RAM shortlist до 32 вариантов сохранён. При одинаковой аппаратной оценке предпочтение получает заводской KIT, затем меньшая цена и только после неё заявленная скорость. DDR4-4600/DDR5-8000 не получают выдуманного прироста и не объявляются запущенными на XMP/EXPO: реальные частоты и слоты платы требуют проверки. Два модуля из одного SKU создаются лишь при подтверждённом остатке и цене обоих.
- Причина наложения UI: общая иллюстрация категории не была ограничена ячейкой карточки; на ширине 320 px фиксированный блок FPS также расширял заголовок до 330 px. Изображение теперь ограничено своей квадратной областью, текст имеет `min-width:0`/перенос, заголовок на узком экране переносится. Добавлена краткая справка о задаче, CPU/GPU, RAM и SSD.

## Скорость и проверка

25 запросов: сумма 182.52 с, p50 7.462 с, p95 10.491 с, максимум 11.249 с. V2 p95 был 10.269 с. Широкий SSD/RAM поиск не дал доказанного ускорения; задержка p95 немного выросла. Конкурентную нагрузку отдельно не сертифицировали.

Математические тесты проверяют Pareto SSD, независимость источников, цель Performance по слабейшему компоненту, CPU Mark на ядро, RAM KIT и отсутствие поддельного FPS. Полная регрессия и E2E приведены в итоговом отчёте этой итерации.

## Ограничения

- 150 000 ₽: V3 выбирает Intel Core i9-14900K + RTX 3070 Ti. Это следствие высокого CPU Mark percentile для Intel и ограничения признаков. Без проверенных single-thread и независимых игровых сравнений нельзя доказать, что этот вариант лучше доступной связки с более сильной GPU. Заголовок Performance обозначает цель алгоритма, а не доказанный максимум FPS.
- 200 000 ₽: выбор RTX 3080 вместо RTX 5070 следует G3D percentile. G3D не учитывает игровые драйверы, VRAM, DLSS/FG и конкретную игру; сравнение не подтверждено игровыми замерами.
- SSD shortlist учитывает подтверждённые модель, объём и интерфейс. Для большинства предложений точные скорость чтения/записи, DRAM, ресурс и тепловой режим неизвестны; им не приписывается оценка.
- При отсутствии скорости/слотов/BIOS платы двухканальность и XMP не гарантированы. Плата/CPU/PSU/корпус требуют проверки технических неизвестных перед покупкой.
- Источник измерений FPS недостаточен для новой калиброванной модели; см. [FPS_ENGINE_V3_STATUS.md](FPS_ENGINE_V3_STATUS.md). `global_optimum_proven=false`: shortlist и time limit ограничивают исчерпывающий поиск на большом каталоге.
